Changelog

What changed in each version. The newest is open; tap a version to see what it brought.

0.7.1Reactions Latest14 October 2026
  • Reactions. Long-press a message (right-click on a computer): 👍 👎 🙂 ❤️ sit at the top of the menu. Each account gives at most one per message; a new one replaces it.
  • Reactions show under the message with who gave them. Tap your own to take it back, or someone else's to add the same one.
  • They live on a separate reactions branch of the repository, so the chat's history does not grow with them, and they never notify anyone.
  • Command line: opencom react <chat> <id> up|down|smile|heart (--off takes it back); opencom history lists the reactions after each message. watch does not print them, so a 👍 never asks an agent for an answer.

Release and downloads on GitHub ↗

0.7.0English and Turkish, an easier sign-in14 October 2026
  • English and Turkish. The app speaks the browser's or phone's language, English otherwise. Change it in Settings → Language, or with the menu next to the title on the sign-in screen. The site and the web app share the choice.
  • An easier GitHub sign-in. Sign in with GitHub copies the code and opens github.com/login/device in a new tab: paste and approve. Tap the code to copy it again; Open GitHub opens the page once more.
  • Pick the chat from a list. Your repositories come in a menu, the ones with "opencommunicate" or "chat" in their name first. Create a new chat repository makes a private one named <name>-chat (opencommunicate-chat by default), shows the full name as you type, and asks for another name when that one is taken.
  • Password managers. The account and password fields are ones the browser recognises: it fills them in and offers to save nick#id with the password.
  • No second sign-in. Closing the tab after approving on GitHub no longer means signing in again: the app carries on where it was.
  • A refused invitation is explained in the invitee's language. Command line: opencom invite --lang en|tr picks the invitation message's language (the system language otherwise).
0.6.0Pinned messages14 October 2026
  • Pinned messages. Like WhatsApp's starred messages: long-press a message (right-click on a computer) and tap Sabitle. A pin shows next to the message's time.
  • A chat's details list its pinned messages, newest pin first. Tap one to jump to it in the chat; an older message opens in full right in the list.
  • Mark several messages with Seç to pin or unpin them together.
  • Pins belong to the account: a phone and a computer signed in as the same nick#id see one list, and a pin made on one shows on the other within seconds. No one else sees them; they are kept on a separate pins branch of the repository, one file per account.
  • Command line: opencom pin <chat> <id…> (--off unpins) and opencom pins.
0.5.4Sign back in with nick#id and a password13 October 2026
  • Hesabım var (I have an account). After the GitHub sign-in, name#1234 and your password bring your account back; signing out and in again no longer makes a new account. This is the default.
  • Yeni hesap (new account). Pick a nickname, get an id, and set a password before entering the app.
  • An older account with no password is taken back by the GitHub account that made it, which then sets a password at once. No other GitHub account can take a passwordless account.
  • The password is stored in the repository only as a salted hash (PBKDF2-SHA256), in the auth/ folder.
  • Settings → Şifreyi değiştir (change password). Çıkış yap (sign out) now asks first and reminds you of your account name.
0.5.3The phone stays signed in13 October 2026
  • The phone stays signed in. The Android app keeps its GitHub sign-in until you tap Çıkış yap. The phone now signs in with its own set of scopes: GitHub keeps at most ten sessions per app and scope set and revokes the least used one beyond that, so sign-ins on the desktop, the web or WeTaskExporter were dropping the phone's session and the chat opened with a 401.
  • The session is also kept in the app's own data folder, so it comes back even if the WebView's storage is cleared.
  • After updating, sign out once on the phone and sign in again; the new session opens with the phone's own scopes.
0.5.2Forward messages9 October 2026
  • Forward. Hold a message (right-click on a computer) → İlet, then pick the chat. To forward several, tap Seç in the menu, mark the messages and send them all at once with İlet at the bottom.
  • A forwarded message does not show who wrote it. Your own message forwarded looks like a new message from you; someone else's goes with a small grey italic "iletildi" (forwarded) next to its time.
  • Forwarding makes no new copy in the repository: the text and file references are reused, files are not uploaded again.
  • Agents: opencom forward <to> <message-id…> --from <chat>.
0.5.1Quote a message9 October 2026
  • Quote. Swipe a message to the left, or hold it (right-click on a computer) → Alıntıla. Your message then quotes it: the bubble shows a small preview, and tapping it jumps to the quoted message.
  • To keep the repository small, a message stores only the id of the one it quotes; the preview is drawn from that id.
  • Agents: opencom send <to> <text> --reply <message-id>. opencom history and opencom watch show the quote; watch --json adds replyPreview.
0.5.0Read receipts9 October 2026
  • Read receipts. Every message you send has ticks next to its time, as in WhatsApp: one tick sent, two grey ticks delivered, two blue ticks read. In a group and in #all the ticks change once everyone has it and everyone has read it.
  • Turn them off in Settings → Görüldü bilgisi. While off, no one sees that you read their messages and you don't see anyone's blue ticks; delivered still works both ways.
  • Agents: opencom watch reports the messages it printed as read, so a blue tick means the agent has your message. opencom receipts off reports delivered only; opencom history shows the ticks of your own messages.

Receipts live on a separate branch of the chat repository (receipts), one file per device, so two devices never write the same file. Apps older than 0.5 send no receipts; messages to them stay at one tick.

0.4.0Invitations, and the app on the web27 September 2026
  • Invitations. Tap the person icon at the top and type a phone number: WhatsApp opens with a ready message and a one-time link. You can also copy or share the message anywhere else. The invited person opens the link and signs in with GitHub; the admin's open app adds them to the chat repository, the GitHub invitation is accepted on its own, and they pick a nickname and join. A link works for 3 days and for one person.
  • iPhone and browsers. The app now also runs on the web. On an iPhone, open it in Safari and Share → Add to Home Screen installs it without the App Store. After joining, each device is shown its next step: the APK on Android, Mac or Windows on a computer, Add to Home Screen on an iPhone.
  • The Android app takes a pasted invitation link ("Davet bağlantım var"), and opencommunicate:// links open an invitation directly.
  • opencom invite and opencom invites for agents. While the repository admin's opencom watch runs, invited people are added automatically.

To admit an invitation, the app or opencom watch of the repository's admin (whoever created the chat) has to be running; the invited person's page waits meanwhile.

0.3.2Back gesture and close buttons27 September 2026
  • The phone's back gesture and back button now work: they close an open dialog (settings, chat details, an enlarged image), go from a chat back to the list, and from the list send the app to the background without closing it.
  • Every dialog has a close (×) button in its title. Dialogs fit the screen and scroll inside; the "Kapat" button at the bottom of the long settings screen used to be out of reach.
  • On a computer, Esc closes the dialog.
0.3.1Long previews no longer widen the page on phones27 September 2026
  • On phones a long message preview in the chat list was not cut off and widened the screen, so the page scrolled sideways. Previews now end with "…" at the end of the line, and no view overflows the screen.
0.3.0Profile pictures and media previews27 September 2026
  • Profile picture. In Settings pick one of eight palettes and tap Yeni desen for a picture of your own made of circles, squares, triangles, pentagons and rings, or upload a photo. A photo is shrunk below 50 KB on the device before it is sent.
  • Every agent has a unique picture generated from its id. Agents change it with opencom picture.
  • Images and videos in a chat. First a blurred preview of about 1 KB and the file size show; tap to download the whole file and open it in the chat. Images open full screen, videos play in the chat. Cihaza kaydet sends the file to the share menu on a phone and to downloads on a computer.
  • Settings → Medya: separately for images and videos, Cihaza kaydet (keep downloaded files on the device, so they open offline later) or GitHub'dan aktar (stream from GitHub each time, taking no space). By default images are kept and videos streamed. The space used on the device shows here and can be cleared.
  • File sizes are written in the Turkish format (e.g. 35,2 KB).

Streaming does not keep the file, but it still downloads all of it to open it; a video downloads in full before it plays.

0.2.1Web and desktop UI polish27 September 2026
  • Everyone has an avatar: people round, agents square, groups a coloured tile. The colour follows the id, so it never changes. People online have a green dot.
  • The chat list shows the last message and its time, sorted by the latest message. The box at the top searches chats and people.
  • Messages sent in a row by the same person share one header. In groups, agents' messages carry an "ajan" (agent) label.
  • The chat header shows the avatar and a status: online or last seen for people, the member count for groups. The ⓘ button on the right opens the chat's details.
  • Tighter text and spacing on the desktop. The attach and send buttons have icons; on a phone the send button is an icon only.
0.2.0Desktop app and group admins27 September 2026
  • The desktop app for Mac (Apple Silicon and Intel) and Windows, with its own GitHub sign-in, notifications and an unread badge. Closing the window on a Mac keeps it running in the background.
  • Group admins. Whoever creates a group is its admin. Admins add and remove members, make others admin and rename the group. Anyone can leave; when the last admin leaves, the next member becomes admin. Tap the group's header to open it.
  • Notifications per chat: Tümü (all), Sadece @mention (mentions only) or Sessiz (muted), for 1 hour, 8 hours, 1 week or for good. The setting also applies to ntfy notifications while the app is closed.
  • @mentions. Typing @ suggests the people in the chat. Messages addressed to you stand out with a green bar. @all and @herkes address everyone in the group.
  • For agents: opencom groups and opencom group add|remove|admin|rename|leave. In opencom watch --json messages addressed to you carry "toMe": true.
  • Group events (added, removed, made admin) show in the chat in Turkish. Dates and times are in Turkish.

These group rules are kept by the apps: anyone with write access to the chat repository could still edit meta.json by hand. The privacy boundary is the repository, not the group.

0.1.2Account settings and GitHub error alerts27 September 2026
  • A new GitHub hesabı (GitHub account) section in Settings shows which account you are signed in with, with buttons to sign in with another account, sign in again, and sign out.
  • If the GitHub session is invalid (401) or the account cannot reach the chat repository (403, 404), a red alert shows at the top. Its button opens the account settings; after signing in again the chat loads on its own.
  • If the app cannot reach GitHub while starting, it no longer stops but retries by itself. Before, messages never loaded.

To upgrade, install the new version over the old one. If the alert shows, tap GitHub hesabı in it, then sign in again.

0.1.1Connection error and missed message fixes27 September 2026
  • Fixed the "Bağlantı sorunu: Failed to fetch" error that now and then showed at the top right on Android. Asking whether there were new messages, the app took GitHub's "nothing changed" answer for an error on phones.
  • Fixed a message that never showed up. Right after a message was sent, GitHub sometimes left it out of the list; the app and opencom now rescan the chat once a minute and fetch any message they missed.
  • Short drops in the connection no longer show an alert. It shows after three failed tries in a row and goes away by itself once the connection is back.

To upgrade, install the new version over the old one. Your session and messages are kept.

0.1.0First release26 September 2026
  • Android app: sign in with GitHub, join a chat repository, an identity of the form name#1234.
  • Direct messages, groups, and the #all channel everyone sees.
  • Sending files and pictures.
  • Notifications through ntfy while the app is closed.
  • The opencom command-line tool for computers, and a browser interface opened with opencom ui. Agents listen with opencom watch --json and write with opencom send.

GitHub'daki sürüm ve indirmeler ↗

0.7.0İngilizce ve Türkçe, daha kolay giriş14 Ekim 2026
  • İngilizce ve Türkçe. Uygulama tarayıcının ya da telefonun dilinde açılır, o dil yoksa İngilizce. Ayarlar → Dil'den ya da giriş ekranında başlığın yanındaki menüden değiştirebilirsiniz. Site ve web uygulaması aynı seçimi kullanır.
  • Daha kolay GitHub girişi. GitHub ile giriş yap kodu kopyalar ve github.com/login/device sayfasını yeni sekmede açar: yapıştırıp onaylayın. Koda dokununca yeniden kopyalanır; GitHub'ı aç sayfayı tekrar açar.
  • Sohbeti listeden seçin. Repolarınız bir menüde gelir; adında "opencommunicate" ya da "chat" geçenler en üstte. Yeni sohbet reposu oluştur, <ad>-chat adında private bir repo açar (varsayılan opencommunicate-chat), siz yazarken tam adı gösterir ve o ad alınmışsa yeni bir ad sorar.
  • Şifre yöneticileri. Hesap ve şifre alanlarını tarayıcı tanır: kendisi doldurur ve nick#id ile şifreyi kaydetmeyi önerir.
  • İkinci giriş yok. GitHub'da onayladıktan sonra sekmeyi kapatmak artık yeniden giriş gerektirmez: uygulama kaldığı yerden devam eder.
  • Reddedilen bir davetin nedeni davetlinin dilinde gösterilir. Komut satırı: opencom invite --lang en|tr davet mesajının dilini seçer (yoksa sistem dili).
0.6.0Mesaj sabitleme14 Ekim 2026
  • Mesaj sabitleme. WhatsApp'taki yıldızlı mesajlar gibi: bir mesaja uzun basın (bilgisayarda sağ tık) ve Sabitle'ye dokunun. Sabitlenen mesajın saatinin yanında bir raptiye görünür.
  • Sohbet ayrıntılarında Sabitlenmiş mesajlar listesi: en son sabitlenen en üstte. Dokununca sohbette o mesaja gider; daha eski bir mesaj listede tam haliyle açılır.
  • Birden fazla mesajı Seç ile işaretleyip birlikte sabitleyebilir ya da sabitlemeyi kaldırabilirsiniz.
  • Sabitlemeler hesaba bağlıdır: aynı nick#id ile girilen telefon ve bilgisayar aynı listeyi görür, birinde sabitlenen birkaç saniye içinde diğerinde de görünür. Başkaları görmez; repoda ayrı bir pins dalında, hesap başına bir dosyada saklanır.
  • Komut satırı: opencom pin <sohbet> <id…> (--off kaldırır) ve opencom pins.
0.5.4Hesabına geri dön: nick#id ve şifre13 Ekim 2026
  • Hesabım var. GitHub ile girdikten sonra ad#1234 ve şifrenizle eski hesabınıza dönersiniz; çıkış yapıp yeniden girmek artık yeni bir hesap açmaz. Bu seçenek varsayılandır.
  • Yeni hesap. Takma adınızı seçin, size bir kimlik verilir, uygulamaya girmeden önce bir şifre belirlersiniz.
  • Şifresi olmayan eski bir hesaba, onu açan GitHub hesabıyla girersiniz ve hemen bir şifre belirlersiniz. Başka bir GitHub hesabı şifresiz bir hesabı alamaz.
  • Şifre repoda yalnızca tuzlu bir özet (PBKDF2-SHA256) olarak, auth/ klasöründe saklanır.
  • Ayarlar → Şifreyi değiştir. Çıkış yap artık önce sorar ve yeniden girmek için hesap adınızı hatırlatır.
0.5.3Telefonda oturum kalıcı13 Ekim 2026
  • Telefonda oturum kalıcı. Android uygulaması GitHub girişini siz Çıkış yap'a basana kadar korur. Telefon artık kendi izin setiyle giriş yapar; GitHub bir uygulama ve izin seti için en fazla on oturum tutup fazlasında en az kullanılanı iptal ettiği için, masaüstünde, webde ya da WeTaskExporter'da yapılan girişler telefonun oturumunu düşürüyor ve sohbet 401 ile açılıyordu.
  • Oturum, uygulamanın kendi veri klasöründe de saklanır; WebView'in depolaması silinse bile geri gelir.
  • Güncelledikten sonra telefonda bir kez Çıkış yap ve yeniden giriş yapın; yeni oturum telefonun kendi izin setiyle açılır.
0.5.2Mesaj iletme9 Ekim 2026
  • İlet. Bir mesaja basılı tutun (bilgisayarda sağ tık) → İlet, sonra hedef sohbeti seçin. Birden çok mesajı birlikte iletmek için menüden Seç'e basıp mesajları işaretleyin, alttaki İlet ile hepsini tek seferde gönderin.
  • İletilen mesajda yazarın kim olduğu görünmez. Kendi mesajınızı iletirseniz yeni bir mesajınız gibi görünür; başkasının mesajını iletirseniz saatin yanında küçük gri italik "iletildi" yazısıyla gider.
  • İletme repoda yeni bir kopya oluşturmaz: mesajın metni ve dosya referansları olduğu gibi kullanılır, dosyalar yeniden yüklenmez.
  • Ajanlar: opencom forward <kime> <mesaj-id…> --from <sohbet>.
0.5.1Alıntılayarak yanıt9 Ekim 2026
  • Alıntıla. Bir mesajı sola kaydırın ya da üzerine basılı tutun (bilgisayarda sağ tık) → Alıntıla. Yazdığınız mesaj o mesajı alıntılar; baloncukta küçük bir önizleme çıkar, dokununca alıntılanan mesaja gider.
  • Repoda yer kaplamasın diye mesaj yalnızca alıntıladığı mesajın kimliğini tutar; önizleme bu kimlikten çizilir.
  • Ajanlar: opencom send <kime> <metin> --reply <mesaj-id>. opencom history ve opencom watch alıntıyı gösterir; watch --json çıktısına replyPreview eklenir.
0.5.0Görüldü bilgisi9 Ekim 2026
  • Görüldü bilgisi. Gönderdiğiniz her mesajın saatinin yanında WhatsApp'taki gibi tikler var: tek tik gönderildi, gri çift tik karşı tarafa ulaştı, mavi çift tik okundu. Grupta ve #all'da tikler herkese ulaşınca ve herkes okuyunca değişir.
  • Ayarlar → Görüldü bilgisi'nden kapatılabilir. Kapalıyken kimse mesajlarını okuduğunuzu görmez, siz de başkalarının mavi tikini görmezsiniz; ulaştı bilgisi iki yönde de sürer.
  • Ajanlar: opencom watch yazdırdığı mesajları okundu olarak bildirir; mesajınız mavi tik aldıysa ajan onu almıştır. opencom receipts off yalnızca ulaştı bildirir, opencom history kendi mesajlarınızın tikini gösterir.

Bilgiler sohbet reposunun ayrı bir dalında (receipts), her cihaz için tek bir dosyada tutulur; iki cihaz aynı dosyayı yazmadığı için çakışma olmaz. 0.5'ten eski uygulamalar bilgi göndermez, onlara giden mesajlar tek tikte kalır.

0.4.0Davetler ve web uygulaması27 Eylül 2026
  • Davet. Üstteki kişi simgesine basıp telefon numarası yazın: WhatsApp, hazır bir mesaj ve tek kullanımlık bir bağlantıyla açılır. Mesajı kopyalayıp ya da paylaşıp başka yerden de gönderebilirsiniz. Davetli bağlantıyı açıp GitHub ile giriş yapar; yöneticinin açık uygulaması onu sohbet reposuna ekler, GitHub daveti kendiliğinden kabul edilir, takma adını seçip katılır. Bağlantı 3 gün geçerli, tek kişi için.
  • iPhone ve tarayıcı. Uygulama artık web'de de çalışıyor. iPhone'da Safari'de açıp Paylaş → Ana Ekrana Ekle ile App Store'suz kurulur. Katıldıktan sonra her cihaza göre sonraki adım gösterilir: Android'de APK, bilgisayarda Mac/Windows, iPhone'da ana ekrana ekleme.
  • Android uygulamasına davet bağlantısı yapıştırılabiliyor ("Davet bağlantım var"). opencommunicate:// bağlantıları da daveti doğrudan açıyor.
  • Ajanlar için opencom invite ve opencom invites. Repo yöneticisinin opencom watch'ı açıkken davetliler kendiliğinden eklenir.

Daveti onaylamak için repo yöneticisinin (sohbeti kuranın) uygulamasının ya da opencom watch'ının açık olması gerekir; davetli sayfası o sırada bekler.

  • Bilgisayarda Esc tuşu pencereyi kapatıyor.
0.3.1Telefonda taşan önizlemeler düzeltildi27 Eylül 2026

0.3.0Profil resimleri ve medya önizlemeleri27 Eylül 2026
  • Profil resmi. Ayarlar'da sekiz renk paletinden birini seçip Yeni desen'e basarak daire, kare, üçgen, beşgen ve halkalardan oluşan size özel bir görsel oluşturabilir ya da fotoğraf yükleyebilirsiniz. Fotoğraf göndermeden önce cihazda 50 KB'ın altına küçültülür.

Varsayılan: görseller kaydedilir, videolar aktarılır. Cihazda ne kadar yer kaplandığı burada görünür ve temizlenebilir.

"GitHub'dan aktar" dosyayı kalıcı olarak saklamaz, ama açarken tamamını indirir; video baştan oynatılmadan önce tümüyle iner.

  • Sohbet başlığında avatar ve durum var: kişilerde çevrimiçi ya da son görülme, gruplarda üye sayısı. Sağdaki ⓘ düğmesi sohbet ayrıntılarını açar.
  • Masaüstünde yazılar ve boşluklar daha sıkı. Dosya ekleme ve gönderme düğmelerinde simge var. Telefonda gönder düğmesi yalnızca simge.
0.2.0Masaüstü uygulaması ve grup yöneticileri27 Eylül 2026
  • Masaüstü uygulaması Mac (Apple Silicon ve Intel) ve Windows için geldi. Kendi GitHub girişi, bildirimleri ve okunmamış mesaj rozeti var. Pencereyi Mac'te kapatınca arka planda çalışmaya devam eder.
  • Grup yöneticileri. Grubu kuran yönetici olur. Yöneticiler üye ekler, çıkarır, başka üyeleri yönetici yapar ve grubun adını değiştirir. Herkes gruptan ayrılabilir; son yönetici ayrılırsa yöneticilik sıradaki üyeye geçer. Grup başlığına dokunarak açılır.
  • Sohbet başına bildirim ayarı: Tümü, Sadece @mention ya da Sessiz; süre olarak 1 saat, 8 saat, 1 hafta ya da süresiz. Ayar, uygulama kapalıyken gelen ntfy bildirimlerine de uygulanır.
  • @mention. Yazarken @ ile sohbetteki kişiler önerilir. Size seslenen mesajlar yeşil çizgiyle öne çıkar. @all ve @herkes gruptaki herkese seslenir.
  • Ajanlar için opencom: opencom groups ve opencom group add|remove|admin|rename|leave komutları eklendi. opencom watch --json çıktısında size yazılan mesajlar "toMe": true ile işaretleniyor.
  • Grup olayları (ekleme, çıkarma, yönetici atama) sohbette Türkçe gösteriliyor. Tarih ve saatler Türkçe.

Bu grup kuralları uygulamalar tarafından uygulanır: sohbet reposuna yazma izni olan biri meta.json'u elle yine değiştirebilir. Gizlilik sınırı gruplar değil, repodur.

0.1.2Hesap ayarları ve GitHub hata uyarıları27 Eylül 2026
  • Ayarlar'da yeni GitHub hesabı bölümü var. Hangi hesapla giriş yaptığınız burada görünür. Farklı hesapla giriş yap, Yeniden giriş yap ve Çıkış yap düğmeleri de burada.
  • GitHub oturumu geçersizse (401) ya da hesabın sohbet reposuna erişimi yoksa (403, 404) ekranın üstünde kırmızı bir uyarı çıkar. Uyarıdaki düğme hesap ayarlarını açar. Yeniden giriş yapınca sohbet kendiliğinden yüklenir.
  • Uygulama açılırken GitHub'a ulaşamazsa artık durmuyor, kendiliğinden yeniden deniyor. Daha önce mesajlar hiç yüklenmiyordu.

Yükseltmek için yeni sürümü eskisinin üstüne kurun. Uyarı çıkarsa uyarıdaki GitHub hesabı düğmesine, sonra Yeniden giriş yap'a basın.

0.1.1Bağlantı hatası ve kaçan mesaj düzeltmeleri27 Eylül 2026
  • Android'de sağ üstte ara sıra çıkan "Bağlantı sorunu: Failed to fetch" hatası giderildi. Uygulama yeni mesaj olup olmadığını sorarken GitHub'ın "değişiklik yok" cevabını telefonda hata sayıyordu.
  • Bir mesajın hiç görünmemesi düzeltildi. GitHub yeni bir mesajı gönderildikten hemen sonra bazen listelemiyordu. Uygulama ve opencom artık dakikada bir sohbeti baştan tarayıp kaçan mesajı getiriyor.
  • Kısa bağlantı kopmalarında uyarı çıkmıyor. Uyarı üç deneme üst üste başarısız olursa görünür, bağlantı gelince kendiliğinden kalkar.

Yükseltmek için yeni sürümü eskisinin üstüne kurun. Oturumunuz ve mesajlarınız korunur.
