Get started

Every client signs in with GitHub and joins one chat repository. The first person creates it; everyone else is invited or added as a collaborator.

1. Install a client

  • Android: download the APK from the download section and open it. Android asks once to allow installs from your browser.
  • macOS: open the DMG and drag OpenCommunicate to Applications. The app is not notarized, so the first time right-click it and choose Open.
  • Windows: run the setup. SmartScreen warns about an unknown publisher: More info, then Run anyway.
  • iPhone, or any browser: open the web app. On an iPhone, Share, then Add to Home Screen makes it an app.

2. Sign in with GitHub

Tap GitHub ile giriş yap. The app shows a short code; enter it on github.com and approve. The app asks for the repo scope because the chat repository is private. Nothing but the GitHub token is stored on the device.

3. Create or join a chat

Enter the chat repository as owner/name. If it does not exist yet, the app creates it as a private repository under your account, or under an organisation where you can create repositories. To join someone else's chat, use their invitation link, or ask them to add your GitHub account as a collaborator.

4. Your account: nick#id and a password

Everyone in a chat is nick#1234. On the first join choose Yeni hesap (new account), pick a nickname and set a password. On another device, or after signing out, choose Hesabım var (I have an account) and enter nick#id and the password: you get the same account back, with your chats and pinned messages.

Choosing Yeni hesap again gives you a new nick#id, a separate account. Use Hesabım var to keep one account across your phone and computer.

5. Notifications while the app is closed

Install the free ntfy app, then in OpenCommunicate open Settings (Ayarlar) and tap Bildirim konusu oluştur. Subscribe to the topic it shows. Whoever messages you posts a short notice there; tapping it opens OpenCommunicate.

Kurulum

Her istemci GitHub ile giriş yapar ve tek bir sohbet reposuna katılır. İlk kişi repoyu oluşturur; diğerleri davet edilir ya da ortak çalışan olarak eklenir.

1. Bir istemci kurun

  • Android: APK'yı indirme bölümünden indirip açın. Android bir kez tarayıcınızdan kuruluma izin vermenizi ister.
  • macOS: DMG'yi açıp OpenCommunicate'i Uygulamalar'a sürükleyin. Uygulama Apple tarafından onaylı olmadığı için ilk seferde sağ tıklayıp Aç'ı seçin.
  • Windows: kurulumu çalıştırın. SmartScreen bilinmeyen yayıncı uyarısı verir: Ek bilgi, ardından Yine de çalıştır.
  • iPhone ya da herhangi bir tarayıcı: web uygulamasını açın. iPhone'da Paylaş, ardından Ana Ekrana Ekle ile uygulama gibi kurulur.

2. GitHub ile giriş yapın

GitHub ile giriş yap'a dokunun. Uygulama kısa bir kod gösterir; kodu github.com'da girip onaylayın. Sohbet reposu özel olduğu için uygulama repo iznini ister. Cihazda GitHub anahtarından başka bir şey saklanmaz.

3. Sohbet oluşturun ya da katılın

Sohbet reposunu sahip/ad biçiminde yazın. Repo yoksa uygulama onu hesabınızın altında, ya da repo oluşturabildiğiniz bir organizasyonun altında özel olarak oluşturur. Başkasının sohbetine katılmak için davet bağlantısını kullanın ya da GitHub hesabınızı ortak çalışan olarak eklemesini isteyin.

4. Hesabınız: nick#id ve şifre

Sohbette herkes nick#1234'tür. İlk katılışta Yeni hesap'ı seçin, bir takma ad seçip şifre belirleyin. Başka bir cihazda ya da çıkış yaptıktan sonra Hesabım var'ı seçip nick#id ve şifrenizi girin: sohbetleriniz ve sabitlenmiş mesajlarınızla aynı hesaba dönersiniz.

Yeniden Yeni hesap'ı seçmek size yeni bir nick#id, yani ayrı bir hesap verir. Telefonda ve bilgisayarda tek hesap kullanmak için Hesabım var'ı seçin.

5. Uygulama kapalıyken bildirim

Ücretsiz ntfy uygulamasını kurun, sonra OpenCommunicate'te Ayarlar'ı açıp Bildirim konusu oluştur'a dokunun. Gösterilen konuya ntfy'da abone olun. Size yazan kişi oraya kısa bir bildirim gönderir; dokununca OpenCommunicate açılır.
