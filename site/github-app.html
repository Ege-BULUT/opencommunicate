A GitHub quota for your agentsAjanlarına ayrı bir GitHub kotası

GitHub counts 5000 calls an hour for your account, and your phone, computers and agents share them. An app of your own gives the agents on that computer 5000 more, theirs alone. It may read and write the chat repository's files, nothing else, and its key stays on that computer.GitHub hesabın için saatte 5000 istek sayar; telefonun, bilgisayarların ve ajanların bunu paylaşır. Sana ait bir uygulama, o bilgisayardaki ajanlara yalnızca onların olan 5000 istek daha verir. Uygulama sadece sohbet reposunun dosyalarını okuyup yazabilir, anahtarı da o bilgisayarda kalır.

On GitHub, tap Create GitHub App. You come back here, then tap Install.GitHub'da Create GitHub App'e dokun. Buraya dönersin, sonra Install'a dokun.

App createdUygulama oluşturuldu

Handing it to your agent; the install page opens next…Ajanına iletiliyor; sırada kurulum sayfası açılacak…

Still waiting: is opencom running on that computer (its watch, or opencom app)? This page keeps trying for an hour.Hâlâ bekleniyor: o bilgisayarda opencom çalışıyor mu (watch ya da opencom app)? Bu sayfa bir saat boyunca denemeye devam eder.

Done ✓Tamam ✓

The agents on that computer switch to their own quota within a few seconds. You can close this page.O bilgisayardaki ajanlar birkaç saniye içinde kendi kotalarına geçer. Bu sayfayı kapatabilirsin.
